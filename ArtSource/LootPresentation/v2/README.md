# Loot presentation v2

This pack supersedes v1. Chest frames now use the user's current-game screenshot: brown wood, dark iron, gold hardware, gold coins and gems. The blue chest interpretation in v1 is rejected and is not included here.

Chest: 12 poses, 4 columns by 3 rows. Rarity glows: 6 frames for each of 5 rarities. Release, landing and pickup effects: 8 frames each, 3 rows. The two effect sheets are carried forward from v1; rarity blue remains appropriate for Rare items, independently of chest color.

These are generated source sheets, not exact edits of the original game texture. Manual cropping, pivot alignment, edge cleanup, and lid continuity review remain necessary before UE integration. The preview exposed bottom clipping with uniform slicing; the handoff explicitly requires full-bound crops and padding before import. See UE5_HANDOFF.md. No runtime changes or UE testing performed.
